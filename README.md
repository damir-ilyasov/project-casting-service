# project-casting-service

Консольное приложение для организации и проведения кастингов:
создание проектов и ролей, регистрация кандидатов, подача и отмена
заявок на роли, поиск, сортировка и статистика.

## Возможности

- просмотр и поиск проектов по названию;
- добавление проектов и ролей;
- просмотр и поиск кандидатов по имени;
- добавление кандидатов;
- проверка доступности роли (занята ли она уже);
- подача заявки кандидата на роль;
- отмена заявки;
- просмотр списка заявок;
- статистика: количество проектов, ролей, заявок по статусам,
  сортировка проектов по числу ролей.

## Структура проекта

- `main.py` — точка запуска, меню приложения;
- `projects.py` — работа с проектами и ролями;
- `candidates.py` — работа с кандидатами;
- `applications.py` — работа с заявками (проверка доступности,
  создание, отмена, статистика);
- `storage.py` — сохранение и загрузка данных в формате JSON;
- `utils.py` — вспомогательные функции безопасного ввода;
- `data/` — JSON-файлы данных (`projects.json`, `candidates.json`,
  `applications.json`);
- `tests/` — автоматизированные тесты pytest.

## Формат данных

Проекты (`data/projects.json`) — список проектов, каждый содержит
идентификатор, название и список ролей:

```json
[
  {
    "id": 1,
    "name": "Сериал",
    "roles": [
      {"id": 1, "name": "Главный герой"}
    ]
  }
]
```

Кандидаты (`data/candidates.json`) — список кандидатов с именем и
контактом. Заявки (`data/applications.json`) — список заявок вида
`{"id", "candidate_id", "project_id", "role_id", "status"}`, где
`status` принимает значения `pending`, `accepted` или `cancelled`.

## Требования

- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:

```

```
