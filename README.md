# project-casting-service

## Назначение

Веб-сервис для организации и проведения кастингов. Приложение предназначено для создания проектов и ролей, размещения информации о кандидатах, участия кандидатов в кастингах и фиксации результатов отбора.

Сервис должен упростить взаимодействие между организаторами кастингов и кандидатами, а также обеспечить удобное хранение и обработку информации о проводимых кастингах.

## Целевая аудитория

Основными пользователями приложения являются: организаторы, кандитат

Организаторы смогут создавать проекты и роли, просматривать кандидатов и фиксировать результаты их участия.

Кандидаты смогут просматривать доступные роли и подавать заявки на участие в кастингах.

## Предметная область

Предметная область проекта связана с организацией кастингов для подбора людей на различные роли в фильмах, сериалах, рекламных проектах, театральных постановках и других творческих проектах.

В рамках сервиса организатор создает проект, определяет необходимые роли, принимает заявки кандидатов и проводит их отбор. Для каждого кандидата по результатам кастинга может быть сохранена информация о прохождении отбора и итоговом решении.

## Основные сущности

- Проект — информация о фильме, сериале, рекламной кампании, спектакле или другом проекте, для которого проводится кастинг.
- Кандидат — пользователь, принимающий участие в кастингах и претендующий на одну или несколько ролей.
- Роль — персонаж или позиция в проекте, на которую осуществляется поиск кандидата.
- Результат — результат участия кандидата в кастинге на определенную роль.

## Основные функции

- создание проекта кастинга.
- добавление роли в проект.
- просмотр всех кастингов.

## План развития

На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
